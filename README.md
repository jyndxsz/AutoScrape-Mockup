## 📌 About AutoScrape Mockup

The **AutoScrape AI** mockup serves as an interactive prototype designed to visually demonstrate how an automated web scraping tool functions on a mobile screen without needing a backend server. 

It operates entirely within your web browser using JavaScript: once you tap **"Start AutoScraper,"** a timer runs every 1.5 seconds to generate fake status logs like `[OK]` or `[DATA]`, automatically streaming them into the terminal box while updating the dashboard's page and data counters in real time.

---

## ⚡ Key Features

* 📱 **Mobile-First Glassmorphic Design:** Optimized dark theme (`#090d16`) with modern glass cards and neon blue glow highlights (`#00d2ff`).
* 📟 **Real-Time Terminal Console:** Simulated log streams (`[OK]`, `[DATA]`, `[RATE_LIMIT]`) with automatic vertical auto-scrolling.
* 📊 **Dynamic Analytics Cards:** Live incrementing counters for pages scraped and data points extracted.
* 🔐 **Authentication Flows:** Interactive tab switching between Sign In and Sign Up views.

## 🛠️ Languages Used

### **HTML5**
* **Role:** Application Structure
* **Implementation:** Layout for authentication forms, terminal console, stats dashboard, and navigation drawers.

### **CSS3**
* **Role:** Mobile Styling & Design
* **Implementation:** Dark theme aesthetic, glassmorphic containers, Flexbox/Grid alignment, and neon blue accents.

### **JavaScript (ES6)**
* **Role:** Interactive Logic & Simulation
* **Implementation:** `setInterval` loop engine, dynamic DOM updates for real-time log streaming, live stat counters, and form tab toggling.
